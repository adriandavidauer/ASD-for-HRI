__TITLE__

Active speaker detection on AVA, UniTalk, WASD and EasyCom, scored with the official AVA script (mAP at 0.5 IoU). Each model is measured twice: on the dataset's own face boxes, which measures the model alone, and with our face detector in the loop, which is what a robot actually runs. Move the version slider to see how each configuration changes from release to release.

The dataset's annotated face boxes go straight to the model, as in the literature. It measures how well the model itself decides who speaks. Time: crop, landmarks or preprocessing, model and averaging per frame.
